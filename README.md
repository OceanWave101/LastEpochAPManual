# Last Epoch Archipelago Manual
Archipelago manual world for Last Epoch

## Requirements
- AP Manual Client
- Last Epoch
- (Recommended) Universal Tracker

## Options & Settings
The [.yaml](/../Manual_LastEpoch_Ocean.yaml) file contains options for modifying your run, including:
- Using or excluding the three dungeons (Lightless Arbor, Soulfire Bastion, and Temporal Sanctum) as campaign skips
- Enabling or disabling traps
  - (wip) Trap weighting

## How to Play
Install the `manual_lastepoch_ocean.apworld` file into your `custom_worlds` folder in your Archipelago install location. (wip)
